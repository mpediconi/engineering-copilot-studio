# Golden Files IEC104

Esta pasta contém os CSVs de referência usados pela aplicação e pelos testes de
regressão.

Os arquivos podem ser abertos para edição pelo Dashboard. Depois de salvar no editor
associado a CSV no Windows, use **Reanalisar Golden** para executar novamente análise e
auditoria sobre o conteúdo atualizado.

Alterações nesses arquivos modificam deliberadamente a linha de base dos testes Golden;
revise os resultados antes de versioná-las.
